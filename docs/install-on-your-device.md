# Install on your device

Expenity is a web app. You can use it in a browser tab, or add it to your home screen so it opens full screen with its own icon, like any other app. The first-run flow shows this with a short animation; these are the same steps.

![The install guide in the app.](images/install.png)

## iPhone and iPad

1. Open Expenity in **Safari**.
2. Tap the Share button.
3. Choose **Add to Home Screen**.
4. Tap **Add**, then open Expenity from your home screen.

## Android

1. Open Expenity in **Chrome**.
2. Open the menu (⋮).
3. Choose **Install app** (or **Add to Home screen**) and confirm.

If your browser offers it, the install step in the app has an **Install now** button that does this for you.

## Computer

In Chrome or Edge, click the install icon at the right end of the address bar, or open the menu and choose **Install Expenity**. In Safari on a Mac: File → Add to Dock.

## Offline

After the first visit the app files are stored on your device, so Expenity opens without a connection. Changes you make offline are saved on the device and sync when you are back online. If a new version is available, it updates the next time you open the app with a connection.

## Several devices

Sign in with the same account on each device. Your wallets, transactions, bills, budgets, goals and settings follow you. How the look is set (theme, animations, language) is remembered per device. See [Account and sync](account-and-sync.md).
