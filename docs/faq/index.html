    FAQ

    Is Duenest free?#

    Yes, and it is open source. There are no accounts, ads or paid tiers today.

    Does it work on my iPhone, Android phone and computer?#

    Yes. It is a web app that runs in any modern browser, and you can install it: see Install on your device. Your data is stored per device, though.

    Can I see my bills on my phone and my laptop?#

    Not automatically yet. Syncing needs a server and is planned. For now, download a backup on one device and restore it on the other, and use the calendar file for reminders everywhere.

    Will it remind me when the app is closed?#

    Through your calendar, yes: download the calendar file from Settings and import it. Duenest itself can only notify you while it is open, because a website cannot wake a phone on its own. Push and email reminders are planned. See Reminders.

    Why not just connect to my bank?#

    Reading a bank account would make Duenest handle credentials and sensitive data, which we would rather avoid. You tell it what you pay, it tells you when.

    Where are my bills stored? What if I clear my browser?#

    In your browser on this device. Clearing site data removes them, so use Settings → Download backup regularly.

    Can several people share the bills?#

    Not yet. Shared households are planned.

    Does it support Greek?#

    Yes. Press ΕΛ at the top, or choose the language in Settings. The app, this help center and the website are in English and Greek, and the sentence box understands both.

    Which currencies?#

    Any currency by its three-letter code. Totals are shown per currency; there is no conversion.

    The sentence box got something wrong.#

    It is a helper. Correct the field in the form below it. If you have a sentence that should work, please open an issue with the exact text.

    How do I report a bug or suggest something?#

    On GitHub.

    Still stuck? Check the FAQ, or ask on GitHub.
