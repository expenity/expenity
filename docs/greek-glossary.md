# Expenity Greek glossary

Register: formal but friendly (εσείς). Short labels where space is tight (tab bar, chips). Finance terms are used the same way everywhere.

| English | Greek | Note |
|---|---|---|
| Wallet | Πορτοφόλι | "Λογαριασμός" is not used for wallets: it also means a bill and a bank account |
| Bill | Λογαριασμός | A payment that comes up, such as electricity |
| Expense / Income | Έξοδο / Έσοδο | Plural Έξοδα / Έσοδα |
| Transaction | Κίνηση | Activity tab: Κινήσεις |
| Budget | Προϋπολογισμός | |
| Goal | Στόχος | Savings goal: Στόχος αποταμίευσης |
| Recurring | Επαναλαμβανόμενο | |
| Transfer | Μεταφορά | |
| Overdue | Εκπρόθεσμος | |
| Net worth | Καθαρή περιουσία | |
| Cash flow | Ταμειακή ροή | |
| Recovery code | Κωδικός ανάκτησης | |
| Passkey | passkey | Left in Latin letters, as in the browsers' own Greek interface |
| Sync | Συγχρονισμός | |

The full list of strings, with the Greek next to the English, is in `greek-review.html` (an editable page) and `greek-review.csv`. Regenerate both with `node dev/greek-review.mjs` after changing `i18n.js`.
